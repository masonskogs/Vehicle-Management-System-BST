# Vehicle-Management-System-BST
A C++ vehicle management system that uses a Binary Search Tree (BST) to organize and manage vehicle records efficiently.

Overview:

This project demonstrates the implementation and use of a Binary Search Tree to store vehicle information. Users can add, search for, display, and manage vehicle records while practicing fundamental data structures and algorithms.

Features:

Add vehicle records
Search for vehicles
Display vehicle information
Organize vehicles using a Binary Search Tree
Traverse the tree to display stored records
Manage dynamic data using nodes and pointers

Technologies:

C++
Binary Search Trees
Pointers
Dynamic memory
Object-oriented programming
Data structures and algorithms

Concepts Demonstrated:

Binary Search Tree implementation
Node-based data structures
Tree traversal
Searching algorithms
Dynamic memory management
Pointers and references

How to Run:

Clone the repository.
Open the project in a C++ IDE such as Visual Studio, CLion, or VS Code.
Compile the source files.
Run the program.

Purpose:

This project was created to strengthen my understanding of data structures, specifically Binary Search Trees, while applying C++ programming concepts to a practical management system.
